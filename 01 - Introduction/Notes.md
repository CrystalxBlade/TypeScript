
# Introduction to TypeScript

## 1. What is TypeScript?

TypeScript is a programming language developed by Microsoft.
It is a superset of JavaScript that adds static type checking.

TypeScript helps developers detect many programming mistakes
before running their programs.

## 2. Why Learn TypeScript?

- Detect type-related errors during development.
- Improve code readability.
- Make large projects easier to maintain.
- Get better autocomplete and editor support.
- Work with React, Next.js, Node.js, and other JavaScript tools.

## 3. How TypeScript Works

1. Write code in a `.ts` file.
2. TypeScript checks the code for type errors.
3. The TypeScript compiler converts it into JavaScript.
4. Run the generated JavaScript using a compatible runtime.

TypeScript itself does not run directly in the traditional
JavaScript execution model without a suitable runtime or tool.

## 4. Important Features

- Static type checking
- Type inference
- Interfaces and type aliases
- Generics
- Modern JavaScript support

## 5. Important Terms

- TypeScript: JavaScript with an additional type system.
- Compiler: A tool that translates TypeScript into JavaScript.
- Type annotation: An explicitly declared type.
- Type inference: TypeScript determines a type automatically.
- Static type checking: Checking types without executing the program.

## 6. File Extensions

- `.ts` - TypeScript source file
- `.tsx` - TypeScript file containing JSX syntax, commonly used with React
- `.js` - JavaScript source file

## 7. Summary

TypeScript builds on JavaScript by adding a type system.
It is especially useful for writing reliable and maintainable
applications as projects grow.
